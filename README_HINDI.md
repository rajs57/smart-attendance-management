# Smart Attendance — GitHub upload package

## Files
- `index.html`: College/Staff page (copied from your provided Attendance_College_Staff.html)
- `super-admin.html`: Super Admin page (copied from your provided SuperAdmin.html)

## Upload to GitHub
1. Create a repository. Keep it **Private** while the Super Admin page is still a standalone HTML demo.
2. Extract this ZIP.
3. Upload `index.html`, `super-admin.html`, and this README to the repository root.
4. Commit the changes.

## Important
These are standalone HTML pages and are not yet securely connected to Supabase. A private GitHub repository alone does not secure a deployed page. Do not publish the Super Admin page publicly until real authentication and server-side authorization are implemented.
